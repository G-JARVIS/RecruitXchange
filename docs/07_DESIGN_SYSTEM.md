# Design System & UI/UX Guidelines

## 1. Brand Color Palette (Somaiya University Inspired)
* **Primary Crimson:** `#800000` (Light Mode) / `#990000` (Dark Mode Accent)
* **Secondary Crimson Hover:** `#660000`
* **Cream / Warm Alabaster:** `#FDFBF7` (Background accent in Light Mode)
* **Dark Background:** `#0F172A` (Charcoal Slate)
* **Card Surface:** `#FFFFFF` (Light) / `#1E293B` (Dark)

## 2. Themes & Micro-Animations
* **Supported Themes:** Strictly Light Mode and Dark Mode.
* **Motion Graphics:** Framer Motion for smooth layout transitions (`framer-motion`), soft hover elevations (`hover:scale-[1.01] transition-transform duration-200`), and smooth accordions.
